# Fotogramas del Hero

Esta carpeta contiene la secuencia demo incluida con la plantilla, nombrada:

```
ezgif-frame-001.jpg
ezgif-frame-002.jpg
ezgif-frame-003.jpg
...
ezgif-frame-288.jpg
```

La configuración correspondiente está en `src/scripts/scrollAnimations.js`:
`basePath`, `frameCount`, `padLength` y `extension`.

Para un cliente real puedes reemplazar esta secuencia por otra. Si cambias el
patrón de nombres o formato, actualiza esos cuatro valores para que coincidan.
